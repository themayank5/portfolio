Featured Case Studies

Three deep-dive projects demonstrating craftsmanship across scalable design systems, generative AI product architecture, and enterprise UX debt audits.

Design System That Scale

"Design Once -> Define the Rule -> Scale With Confidence."

Built a scalable 3-layer design system which is Foundation → Semantic → Component—reframing screen design from “how this screen looks” to “what rules future screens must follow.”

A design system is not just a collection of components, it is a system of decisions that creates consistency.

Impact:

Shared token language across 50+ engineers, WCAG 2.1 AA compliance with AAA contrast targets for key UI elements, 25% reduction in product delivery time

Proptifi — AI Property Visualization

"Making complex AI tools feel immediate, predictable, and trustworthy for non-technical users."

Designed an AI-powered SaaS platform making property transformation approachable for non-technical users through a unified upload → configure → generate → compare workflow across 5 generative tools (Fresh Look, Sky Color, Colors & Textures, Text-to-Image, and Precision+).

Impact:

Reduced property staging turnaround from days to minutes · Built high user confidence through real-time preview

AI Command Center

"Resolving accumulated UX debt through systematic tokens and verified contrast rules."

Audited and systematically restructured accumulated UX debt in an enterprise AI dashboard — creating 48 color tokens, 79 context-scoped typography styles, and validating contrast ratios to strict WCAG AA/AAA compliance across both dark and light surfaces.

Impact:

48 color tokens · 79 typography styles · 100% WCAG AAA contrast compliance eliminating cross-team friction

SYSTEMS & PRACTICE

How I actually work.

Great enterprise interfaces don't happen by accident. They are built on deliberate systems thinking, technical fluency, and disciplined focus on user clarity.

01 ◎

Systems Thinking

I don't design isolated screens; I design the scalable rule engines that generate them. From semantic design tokens in Figma Variables to production CSS custom properties, every pattern serves dozens of future use cases.

Visual Design Interaction Design Design Tokens Component Libraries Responsive Design Micro-interactions
02 ⌘

Design to Code

I design and build responsive interfaces that adapt seamlessly across large, medium, and small screens. I think through layout behavior, component states, content hierarchy, and implementation constraints early, making design-to-development a continuous conversation rather than a handoff.

Angular UI React UI HTML5 CSS3 Bootstrap Responsive Design Design-to-Code QA
03 ↔︎

Legacy Transformation

When I inherit a legacy product, I don't start from a blank canvas, I start by mapping what's already there. I simplify dense interfaces, rebuild information hierarchy, and streamline workflows while respecting the patterns users already know, so improvements land without retraining anyone.

Information Architecture Workflow Simplification Legacy Modernization Cognitive Load Reduction
04 ⬡

Accessibility by Design

I treat accessibility as a foundation, not an audit checklist at the end of a project. WCAG 2.1 principles shape my decisions on color, typography, interaction states, and focus behavior from the start, so the result stays usable across different needs and devices by default

WCAG 2.1 AA/AAA Contrast Auditing Accessible States Keyboard Navigation
Philosophy & Values

Beyond the job title.

I enjoy solving problems where the interface is only one part of the challenge. I look at the bigger picture user needs, information architecture, business goals, accessibility, and technical constraints to create experiences that are clear, useful, and practical.

My experience with design systems and frontend development helps me think through responsive behavior, component states, edge cases, and implementation constraints early making collaboration with engineers more effective.

I'm especially drawn to complex enterprise products, SaaS platforms, and AI-powered workflows where thoughtful design can turn complicated processes into simpler, more confident user experiences.

Clarity over decoration

Every element should have a purpose. I focus on clear hierarchy, meaningful interactions, and simple workflows that help users understand what matters and what to do next.

Accessibility from the beginning

Accessibility is part of the design process, not a final checklist. I consider contrast, focus states, keyboard interaction, readable content, and inclusive experiences from the foundation of a product.
